# J 메이커 (J-Maker) — 오늘만 J가 되어보자

미루는 P를 위한 초 단위 루틴 타이머. 빌드 과정 없는 PWA(웹앱)라 폰 브라우저에서 바로 열리고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 실행

```bash
cd j-maker
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 배포 (폰에 설치하기)

`.github/workflows/deploy-j-maker.yml`이 `main` 브랜치에 `j-maker/`가 바뀔 때마다 **이 폴더만** GitHub Pages에 올립니다. 저장소의 다른 파일(트렌드 리포트 등)은 공개되지 않습니다.

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. 이 작업을 `main`에 합칩니다(또는 Actions 탭에서 워크플로를 직접 실행).
3. 주소는 `https://imber123.github.io/-/` 형태가 됩니다.

> 비공개 저장소에서 GitHub Pages를 쓰려면 GitHub Pro 이상이 필요합니다. 무료 플랜이라면 j-maker만 담은 공개 저장소를 따로 만들거나, Netlify Drop(app.netlify.com/drop)에 `j-maker` 폴더를 끌어다 놓으면 바로 HTTPS 주소가 생깁니다.

설치: 아이폰 Safari 공유 → **홈 화면에 추가**, 안드로이드 Chrome 메뉴 → **앱 설치**.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 껍데기, PWA 메타 태그 |
| `styles.css` | 다크 네온(기본) / 미니멀 파스텔 / 아케이드 스킨, 동작 애니메이션 |
| `app.js` | 루틴·타이머·팩폭 멘트·음성·효과음·기록 전체 로직 |
| `media.js` | 동작별 3D 영상 연결표 (영상이 생기면 주석만 풀면 됨) |
| `media/README.md` | 3D 영상 제작 가이드 (목록, 규격, 투명 배경, 넣는 방법) |
| `manifest.webmanifest`, `sw.js` | 설치·오프라인 지원 |
| `icons/` | 제공받은 앱 아이콘을 잘라 만든 PNG (96/180/192/512) |

## 작업지시서보다 더한 것 (제안 반영)

- **출발 시각 역산**: 루틴에 "08:30 출발"처럼 마감 시각을 정하면 홈 카드에 "07:58까지 시작 · 12분 여유"가 보입니다. 홈을 켜 둔 채 시작 시각이 되면 말로 재촉합니다. 이미 늦었으면 **⚡ 단계별 65%로 압축해서 시작** 버튼으로 모든 단계를 남은 시간에 맞춰 줄여 시작합니다. 타이머 화면에는 "마감 08:30 · 3분 여유/늦음"이 계속 표시되고, 완료 화면에 마감 대비 결과가 나옵니다.
- **3D 영상 자리**: 동작별 영상이 있으면 이모지 대신 재생되고, 10초 남으면 '다급한' 버전으로 바뀝니다. 폰에서 직접 영상을 올려 단계별로 시험해 볼 수도 있습니다(`media/README.md`).

- **완료 예정 시각 표시**: 홈 카드에 "지금 시작하면 08:10 완료"가 보이고, 타이머 화면 오른쪽 위에는 연장할 때마다 다시 계산되는 완료 예정 시각이 보입니다. 지각 위기인 사람에게는 남은 분보다 몇 시에 끝나는지가 더 와닿습니다.
- **J 지수와 등급**: 끝나면 연장 시간, 일시정지 횟수, 일찍 끝낸 시간으로 점수를 매겨 `파워 J` / `J 꿈나무` / `J인 척하는 P` / `자연인 P` 등급을 줍니다. 공유하고 싶어지는 결과 화면을 노렸습니다.
- **연속 달성 기록**: 홈에 "🔥 3일 연속 J"와 이번 주 완주 횟수를 표시합니다.
- **호칭 설정**: "P님" 대신 원하는 이름으로 팩폭을 받을 수 있습니다.
- **이모지 자동 추천**: 단계 이름에 "머리 말리기"라고 쓰면 💨와 바람 모션이 자동으로 붙습니다.
- **화면 꺼짐 방지**(Wake Lock): 타이머가 도는 동안 화면이 꺼지지 않습니다.
- **이어하기**: 앱이 닫혀도 진행 중인 루틴을 기억했다가, 다시 열면 흐른 시간을 반영해 이어 갑니다.
- **J·P 마스코트**: 아이콘의 J·P 캐릭터를 SVG로 다시 그려 말풍선 아바타와 완료 화면에 넣었습니다(J가 P를 쓰러뜨림).

## 알려진 한계

- **백그라운드 알림**: 웹앱은 화면이 꺼지거나 다른 앱으로 가면 타이머 실행이 늦어지거나 멈춥니다(특히 iOS). 그래서 화면을 켜 둔 채 쓰는 페이스메이커로 설계했고, 다시 열면 시간을 따라잡습니다. 잠금 화면 푸시가 꼭 필요하면 네이티브 앱(React Native/Expo)으로 옮겨야 합니다.
- **음성 품질**: 브라우저와 OS에 내장된 한국어 음성을 씁니다. 기기마다 목소리가 다르고, 일부 안드로이드 기기에는 한국어 음성이 없을 수 있습니다.
- **진동**: iOS Safari는 진동 API를 지원하지 않습니다.
- **3D 애니메이션**: 영상이 들어오기 전까지는 이모지와 CSS 모션으로 동작합니다.
